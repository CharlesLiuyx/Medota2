# 全项目 i18n 交接

状态：2026-10-07已实现并通过本机组合检查。规则见[全局国际化Spec](../specs/global-i18n.md)，实现范围、数据基线、检查结果与复跑命令见[验证记录](../history/2026-10-07-global-i18n.md)。

## 维护入口

- 顶栏语言和请求上下文：`src/i18n/`、`src/proxy.ts`、AppShell、VersionLink。默认启用`zh-CN/en`，URL优先于偏好。
- 新增语种：登记语言本名、Intl、文字方向、回退及游戏资料映射；加入完整消息资源，通过键／占位符与浏览流程检查。资料映射不能改变Catalog或语言副本身份。
- 游戏术语：优先使用官方 VPK token；`src/i18n/official-terms.json`保留双语原值和固定来源，按 Spec 审阅等义映射。应用句子中的词语也须一致。
- 新增文案：整句登记资源，客户端用Provider、服务端取请求语言、纯presentation显式传locale；Canvas、ARIA、metadata与状态同等受控。
- 来源缺译文：使用同版已有内容并标注实际语种。外部原文和机器数据不写进应用字典冒充翻译。

当前交付可在共享工作台体验中英文；跨机器继续按环境登记与现有平台交接复验，不复用本机忽略目录作为验收凭据。
