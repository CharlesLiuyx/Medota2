# ADR 0007：共享开发工作台与按需验证

- 状态：Accepted
- 日期：2026-10-06
- 依据：用户批准的[开发脚手架方案](../reviews/development-scaffold-review-2026-10-06.html)
- 替代：ADR 0006 中日常每次验证独占全部资源、CI 默认全量 verify 的要求；ADR 0005 中本地开发 Web 每次借用连接都执行完整身份审计的要求。

## 决定

单人使用多个 AI Session 时，默认共用工作目录、分支、开发 Web、编译缓存和选定的本机数据库。`pnpm dev` 启动或连接同一个 3000 工作台。日常预览优先读取已有 local-review 真实 Catalog 与资产，没有真实环境时才使用 development 样例；可由 `MEDOTA2_WORKBENCH_DATA` 显式选择。真实预览启动时检查资产覆盖，小样例单独重算，不替换页面数据。开发状态与小样例结果直接显示在当前业务页面；Next.js 负责界面热更新，独立计算进程负责样例重算。保存合并触发，旧任务不能覆盖新结果。

数据库保留现有角色权限、来源和持久数据约束。开发 Web 在物理连接首次使用时完整验证，后续复用连接；诊断及正式环境继续完整验证。本地迁移后重启开发服务，使连接与验证状态更新。写入操作继续使用明确的数据库用途与现有权限。

普通浏览 E2E 连接共享开发服务。需要固定 fixture 或破坏性数据库检查时，使用一个可复用测试栈，在锁内顺序运行；浏览器状态、日志、测试产物每次独立。全隔离模式保留用于环境合同测试和排障。仅清理工具自己创建的测试资源。

`pnpm check` 按文件和功能选择格式、静态检查、短使用流程和必要构建。输入摘要覆盖有关代码、测试、fixture、工具链和执行条件；变化期间的结果标为过期。相同条件才复用。本地与 CI 使用同一选择规则。CI 先规划，再准备需要的浏览器和数据库。全量 verify 是显式诊断。

跨工具规则写在 AGENTS.md，稳定概念在 CONTEXT.md，进度在 docs/current.md；每个 Session 在 Git 忽略的本机目录维护自己的记录。Git 暂存/提交、依赖安装、数据库写入与性能基准仅短时串行。

计算先使用现有 TypeScript 和真实解析器。记录耗时与内存，运行可取消，保留输入输出边界；新增语言或平台仍需有证据的独立决定。部署目标尚未确定，发布入口先构建并验证可复用产物。

## 迁移与验证

分步更新脚本、文档和 CI；保留已有数据、可用测试和显式全隔离命令。用两次并行启动、同页更新、真实样例重算、选择范围与缓存失效、固定 fixture 使用流程验收。新模型接手仍需实际跑通一次小改动；文件兼容不自动证明模型能力。

## 2026-10-07：开发编译与扫描边界

共享工作台、独立预览及浏览测试改用已锁定Next 16.3.3自带的Turbopack；发布构建保留webpack。相同真实数据与顺序请求下，Turbopack降低了目录及详情的首次访问时间；其共享manifest写入使用临时文件加rename，减少直接覆盖过程中读取空文件的窗口。原webpack服务曾出现空manifest／JSON解析失败，受控短测没有再次复现，因此不将切换后的短时通过解释为已证明全部历史500的来源。

Tailwind扫描限定`src/`，避免文档、测试和数据锁变化触发全站样式构建。后台开发面板停止轮询，返回时同步最新版本。浏览器扩展改写根节点应在浏览器侧隔离，不关闭应用的hydration校验。具体测量和验收边界见[开发反馈修复记录](../history/2026-10-07-development-feedback.md)。

## 2026-10-08：真实预览的读取稳定性

共享工作台使用的development和local-review都按物理Web/read连接首次完整验证、后续复用身份；显式工作台标记是必要条件。每次借用仍验证session role、恢复会话与只读事务，新连接重新完整验证；独立local-review、test、production及写入操作保持原审计规则。迁移／权限变化后重启工作台。

变化页每个Catalog端点在一个可重复读事务内顺序读取13组查询，再按实体索引组装来源与数值，避免每页26次并发借用和重复全表扫描。空闲连接断线由连接池移除，进程保留；读取中断销毁该连接，后续请求重新验证。仅已识别连接故障转换为可重试状态，身份／权限／解析错误继续失败，驱动私密信息不进入错误对象。依据见[事故与验收](../history/2026-10-08-database-read-resilience.md)。
