# ADR 0009：统一版本读上下文与端点语义 Diff

- 状态：Accepted
- 日期：2026-10-07
- 关联：[实体版本合同](../specs/entity-versions.md)、[实施任务](../work/entity-version-diff.md)

## Context

Catalog是不可变原子目录，地图、图片和客户端证据各自独立。产品仅从current head查询会隐藏历史；直接用补丁号作为全局主键又会误合并多个构建或来源。

## Decision

复用全量快照，为每个已发布完整Catalog形成稳定Release读入口，用URL release统一顶栏、列表、详情、关系、缓存和预取。Catalog head选择默认入口，显式历史查询选择自己的版本。只按有来源依据的同补丁唯一地图关联，新版本提升前统一核验全部产品实体、本地化、图片状态与地图资源；缺项保留候选。历史地图入口作为唯一对应完整版本的别名，产品选择器不再公开仅地图版本。客户端构建独立记录。

版本之间直接比较两个端点的完整投影，按稳定身份、字段路径、关系和已解析机制返回结构化变化及双方来源。未知结构／缺来源／实现升级分别呈现，不累计中间事件，不把缺数据当作删除。导入门禁Diff继续负责候选审阅，浏览Diff不移动head。

不增加数据库表；现有快照导出和来源保留可承载下一次更新。Unit Dataset持久化、地图区域身份、完整脚本机制及可靠重命名映射另行扩展，不通过猜测身份提前宣布完整支持。

## Consequences

旧数据无需迁移，历史版本和默认入口可同时查询；无release的页面入口会固定成可分享URL。全部收录内容仍依赖对应来源与兼容资产，缺项有独立状态。

本决定替代[ADR0001](0001-hero-catalog-version-boundary.md)中“产品只通过head读取”的限制；原子版本、不可变快照和候选校验保留。[ADR0003](0003-catalog-refresh-gates.md)的发布／人工审阅要求不变。后续真实更新与跨机器往返验收单独记录，不以本轮架构测试代替。

2026-10-07 用户明确要求所有实体随版本完整收录。本决定据此收紧最初允许独立地图公开版本的边界；地图来源Dataset与隔离验证工作台继续存在，产品入口统一使用完整Catalog。
