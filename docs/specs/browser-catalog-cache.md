# 浏览器优先的图鉴缓存

2026-10-11 扩展共享版本资源。完整目录持久化覆盖英雄与技能，另保存表格已选列值及地图视野场景。单位与物品使用服务端复用的固定来源投影、路由缓存和浏览器内筛选，尚无完整离线目录副本。

## 用户操作

首屏保持服务端可读内容。浏览器先查内存和 IndexedDB，有同版本完整快照时直接恢复；没有时后台同步当前语言的全部目录资料及预计算搜索词。在线分页给本机恢复保留 200ms 窗口，避免刚重载就抢先发出重复 cursor 请求；超时仍可继续在线加载。就绪后，搜索、拼音／别称匹配、筛选、排序和后续分块渲染都在本机完成，不再发送列表查询或分页请求。输入法组词、URL 恢复与原有筛选语义不变。

当前目录就绪后预加载同语言的另一个目录；省流模式、2G 网络、后台标签和离线时跳过预加载。首次切换未保存的语言只同步该语言资料一次，随后也走本地查询。目录仍按上方 7×／下方 10× 视口分块挂载，数据完整不意味着全部 DOM 同时展开。

已打开页面在断网后可以继续查询已保存的目录。IndexedDB 被禁用或写入配额不足时保留内存缓存；同步失败时使用既有在线 cursor API。页面壳、未预取的详情和缺失图片仍可能需要联网；本实现不提供完整离线安装或 Service Worker 页面缓存。

## 版本与增量同步

现行 `REPLICA_SCHEMA=3`。名称补充及其双语搜索词改变派生内容，因此协议2及更早的IndexedDB／内存副本重新同步；名称来源与适用范围见[语义UI](semantic-game-ui.md#经过审阅的名称补充)。

| 层次      | 身份与失效                                                          | 范围                                                      |
| --------- | ------------------------------------------------------------------- | --------------------------------------------------------- |
| 内存目录  | 环境／数据类别／run／安全指纹、协议版本、实体、语言、Catalog、asset | 共用48MiB／128项预算；并发共享Promise，失败可重试         |
| IndexedDB | 与内存相同；每次读取验证完整块摘要                                  | 每个实体／语言／环境保留 2 个版本，总计最多8个快照／48MiB |
| 内容块    | 16 个稳定 ID 分桶，各自 SHA-256                                     | 新版本只传缺少的块；只换 asset 时可复用全部玩法资料块     |
| 页面导航  | Next.js Router Cache，300 秒                                        | 复用已访问／已预取页面，刷新立即重新读取                  |
| 图片      | 沿用固定 asset 版本和既有 HTTP 缓存                                 | 不混用当前版本与历史目录                                  |

- `POST /api/catalog/replica` 是只读同步查询。输入实体、语言、Catalog／asset 成对版本和最多 16 个已知哈希；返回 manifest 与缺少的内容块。固定版本必须在数据库中存在并通过环境身份验证，单个目录上限 20,000 条，超过时保留在线查询。
- 每个块包含列表行、预计算搜索词以及筛选需要的完整归属关系。浏览器无需加载拼音词库，客户端和服务端使用同一搜索匹配算法。技能历史归属和升级授予状态也参与筛选，不能只按可见 owner 摘要过滤。
- 浏览器按摘要合并新旧内容，验证协议、实体、语言、版本、块 SHA-256 和总条数，再用一次 IndexedDB 事务发布完整快照。中断或校验失败不会把半份数据设为可用。损坏缓存重新获取，旧版本在新版本未就绪前保留。
- `GET /api/catalog/head` 只返回当前 Catalog／asset 指针并提供 ETag。可见目录每 60 秒、重新聚焦或恢复网络时检查，频率合并至最多每分钟一次；未改变返回 304，无正文。
- URL显式release时固定Catalog／asset副本，不轮询head或自动切换；入口固定版本、搜索清空与跨页面链接按[实体版本合同](entity-versions.md)。无显式版本的兼容路径检测到新版本后先同步当前目录的新快照，再调用路由刷新，统一切换页面资料与版本标识。普通搜索／筛选不检查 current head。离线或检查失败继续保留之前验证过的版本。
- 服务端 current head 每个请求重新读取；React 请求内去重不构成跨请求缓存。服务端快照缓存上限 8，数据仍由不可变 Catalog 和已校验来源产生。协议或展示转换发生不兼容变化时必须增加 `REPLICA_SCHEMA`。

## 交互稳定性

悬停仅通知当前和上一个锚点；翻页追加不会重新绘制所有卡片。在线列表切换成本地快照时，首条实体 ID 相同的块保留 DOM 链接，避免在 pointerdown／pointerup 之间替换节点导致点击丢失。

顶栏完整预取各图鉴路由，点击未完成时立即显示细线与`aria-busy`，当前页标记只随实际路由切换。卡片停留或聚焦120ms后只为活动锚点启用详情预取。开发模式由Next.js关闭自动路由预取；已访问路由和资料缓存仍生效。反馈、内容出现和可交互时间分开测量，见[本轮性能验收](../work/tab-cache-performance.md)。

## 共享资源与容量

`ResourceCache`统一已完成值的LRU、字节预算和并发Promise；失败不落缓存，超预算仍向当前请求返回结果。服务端在环境、Release、资产head、来源文件hash等适用校验之后复用纯数据投影；可变head和来源登记不使用跨请求固定值缓存。目录副本48MiB／8项，搜索32MiB／8项，属性160MiB／2项，单位／物品各48MiB／2项，Diff端点96MiB／6项及比较48MiB／6项；未取得可选来源的临时结果不永久保留。计量为序列化内容大小，不等于进程堆上限。

浏览器共享内存总预算48MiB／128项。键包含环境、数据类别、run、数据库安全指纹和资源版本；具有数据库身份的响应必须核验身份头。资源调度最多并发2项，后台最多占1项，为交互保留余量；交互可提升排队资源优先级。卸载后共享下载仍供其他消费者复用，旧组件不提交迟到结果；网络超时／失败后可重试。

英雄／技能IndexedDB v2通过精确key读取当前快照，寻找增量基线时按family索引最多读取2份；淘汰只扫描元数据，总计8份／48MiB、每family最多2版。通用资源库精确读取并校验SHA-256，元数据独立保存，总计128份／32MiB、每family最多2版。容量不足、损坏及禁用均回退到网络／内存，不影响正确读取。

属性首屏将查询地址与SSR结果成对播种，避免挂载后重复请求；查询缓存60秒，核验所选Catalog与响应身份。表格GET只取完整列目录，POST按已选语义列取全部对象的值；列值按来源修订＋列key缓存，并发与重复切换复用。水合完成后，已完成的内存目录与列值在首次渲染同步恢复；所选列全部命中或为空时不再通过异步状态重复发布。组件结果绑定完整环境身份与来源修订，补列保留已有值。排序必须等对应列覆盖全部对象，不以当前可见行排序。来源修订变化返回409，重试先失效并重取目录；列加载失败保留已有值。地图场景及变化依据的延后读取分别遵守[地图](map-explorer.md)与[实体版本](entity-versions.md)合同。

## 验证入口

`pnpm dev` 在首次报告就绪前顺序预热英雄／技能目录、各一条详情与缓存接口，避免第一次导航遭遇冷编译的整页热更新；只读、固定数量，失败保留在线路径。

沿用 `pnpm dev`；修改 Next 配置后顺序执行 `pnpm dev:restart`。无新依赖、数据库迁移或后台服务。

- `pnpm check --plan` / `pnpm check`：按变更范围运行或复用检查。
- `pnpm test:e2e tests/e2e/local-catalog.spec.ts`：比较浏览器与在线筛选结果；验证同版本零内容增量、ETag 304、断网查询、重载后复用 IndexedDB、损坏恢复，以及下载恰好发生在点击期间的回归。
- `pnpm test -- tests/unit/catalog-replica.test.ts tests/unit/hover-tooltip.test.tsx`：验证单条变更只影响一个块、asset-only 复用、200 个锚点仅更新两个组件及停留预取取消。
- 既有在线回退测试显式阻断快照下载，继续验证取消、乱序响应和失败路径；既有无限列表测试继续验证分块、回收与恢复。

显式历史版本浏览不展示其他版本后续导入失败提示；失败提示只用于当前默认Catalog。
