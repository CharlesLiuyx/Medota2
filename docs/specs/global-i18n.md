# 全局国际化

状态：已实现。2026-10-07按全项目与全工作流范围制定并落地；本机检查与边界见[验证记录](../history/2026-10-07-global-i18n.md)，维护入口见[交接](../work/global-i18n.md)。本合同负责语言选择、应用文案、格式化和各模块的语言边界。游戏来源与版本规则继续由[语义UI](semantic-game-ui.md)、[浏览器缓存](browser-catalog-cache.md)和[实体版本](entity-versions.md)负责。

## 目标与验收边界

应用支持显式登记的任意数量语种，以BCP 47代码（含必要地区，例如`zh-CN`、`zh-TW`、`en`、`ja`）标识。本次按用户指定正式启用简体中文`zh-CN`与英语`en`，不把二元选择写进全局架构。每个启用语种都是完整的应用界面语言。顶栏的唯一语言入口控制整个应用，包括各图鉴、详情、地图交互与画布、经济与寻路、版本比较、空状态／加载／错误、来源说明、开发工作台与数据库检查页、设计系统和无障碍文本。页面标题、日期、数字、带数量的句子随语言显示。

游戏资料中的名称、描述与官方更新说明是有版本、有来源的内容；应用界面文案是随代码发布的资源。数据库字段、内部ID、commit、文件路径、原始JSON、原始来源文本、用户搜索词、命令和机器日志不因语言切换改写。没有同版译文时按下述规则显示来源回退，不能把未完成的应用翻译解释成来源回退。

## 语言上下文与路由

优先级：有效URL `lang` → 已保存偏好cookie `medota2-locale` → `zh-CN`。不根据IP猜语言。可用语种来自统一注册表，包含代码、语言本名、Intl语言标记、文字方向、应用回退语言与游戏来源映射。顶栏按注册表提供语言本名，切换保留路径、release、搜索、筛选、比较端点及hash；清空只清业务筛选。浏览器前进后退恢复URL指定语言，并更新偏好。重新打开无lang入口使用已保存偏好。

请求代理只负责解析请求语言并写内部请求header；服务端读取统一上下文，不能信任客户端自带的内部header。客户端Provider使用同一初始语言，URL变动优先，更新html lang与cookie。cookie是一年期、Path=/、SameSite=Lax的非敏感显示偏好，无数据库用户表和额外服务。

内部页面链接、对象形式链接、GET表单、重定向、旧地图URL和模块跳转传递lang；外链、API、文件下载与页内锚点不追加参数。API现有显式locale/lang合同保持有效，不隐式用cookie改变版本化资料响应。非法业务查询继续校验；未知偏好安全回退；SSR和客户端不可使用进程级可变全局locale。

## 文案与格式化架构

`src/i18n`提供纯语言类型／解析、可在服务端及浏览器共享的文案资源、纯翻译与插值／格式化、服务端请求适配、客户端Provider和hook。采用现有TypeScript与Intl，不新增框架或依赖。

- 应用文案集中登记默认语言与每个启用语种，按界面语义组织；消息键保持稳定，中文源消息作为可读键时，改动必须同时维护所有语言。业务代码不得自行拼接翻译后的半句。
- 参数消息使用命名占位符；每个启用语种参数集合一致，数值与实体名称由调用方传入。富文本通过React节点组合，翻译不注入HTML。
- React客户端使用稳定的翻译函数；服务端显式取请求语言；纯presentation函数接收locale。禁止在模块加载时读取请求／浏览器语言，禁止事后扫描DOM替换文字。
- 可访问性名称、placeholder、title、alt、页面metadata与Canvas文字和可见文案同等受控。对source-owned字符串走明确的展示适配，避免把API键、搜索别名与逻辑比较条件翻译掉。
- 数量／日期由Intl按locale格式化。游戏数值精度、技能等级分隔、坐标、hash及排序身份保持原有语义。文档lang/dir由注册表驱动；时间显示指定项目展示时区，避免SSR／浏览器不一致。
- UI缺少译文属于检查失败；真实来源缺译文才允许回退。开发期间有显式回退帮助定位，不能作为完成验收依据。

## 游戏内容与计算边界

### 官方 VPK 初始语料

应用词典中的游戏术语优先引用 Dota 2 官方 VPK 本地化文案。初始资源 `src/i18n/official-terms.json` 按已审阅的语义绑定消息键与官方 token，提取 `dota_schinese/english.txt`、`abilities_schinese/english.txt` 中所需的短标签；完整文件留在可选外部来源。当前基线是 7.41f、ClientVersion 6944、commit `f4c45719314754567cb4ef4fe343bbc790a311f4`。资源保留原始中英文值、来源仓库、commit、文件路径、客户端版本、URL、完整文件 SHA-256、提取时间和提取器／schema 版本。

词典合并优先级为：已绑定的官方词汇 → 项目审阅的语种资源 → 应用默认资源。只去除官方标签的 HTML 外观标记、首尾空白和末尾字段冒号，保留词语与英文大小写；不根据英文同名自动匹配，不复制陈旧机制说明或公式。官方没有等义 token 的导航、流程、状态和项目说明由项目翻译，并保持游戏词汇一致；相关中文整句覆盖在 `src/i18n/zh-CN.json`。中文可读消息键是稳定身份，显示词语调整不改路由、枚举或搜索身份。

此资源只负责随代码发布的应用术语初始语料。实体名称、说明、机制、数值标签仍优先采用所选 Catalog 同版本的官方文本，不能用初始词库覆盖旧版或新版资料。新增语种须核对相应官方文件；更新词汇须重新核对 token 的实际语义、来源版本与文件哈希，通过字典完整性、占位符和官方措辞回归。来源缺失时不得将机器翻译标成官方文案。

应用locale与资料locale分开：应用语种可多于当前Catalog已存的`zh-CN/en`。注册表显式指定资料映射；无对应来源时选择同版可用资料并标注原文语种，不把浏览器偏好写入数据。URL的lang代表应用语种，资料API与缓存继续使用数据合同中的locale。游戏名称、描述、命石、技能数值标签按选定Catalog读取映射后的资料locale；首选请求语言，缺失时使用同版本已有可读译文，并保留来源语言说明。完全缺失时显示本地化的缺项提示，不展示内部ID冒充名字，不生成虚构译文。

地图静态点位和图层按kind、team及已知语义本地化；原始label、坐标与来源证据保持原值。搜索索引继续同时覆盖两种语言；切换不会修改地图Dataset、路线几何、耗时、经济计算或Worker缓存。画布标签随locale重绘，不能每帧重建词典／反复测量相同文字；已有选点、视口、工具和计算记录保持可用。

版本变化页按locale构建两端名称字典与属性标签，语言不参与差异比较身份。官方原文与项目可读译文分开保存和标示；没有译文时标注来源语言，不把来源正文当作应用文案静默翻译。缓存如果存储已格式化文字则必须包含locale，纯计算缓存无需新增语言维度。

## 全工作流验证

1. 每个启用语种分别首次打开目录和深链接，检查html lang、metadata、可访问性名称、资料与界面一致，无水合错误。
2. 切语言保留版本／筛选／实体／hash；跨六个顶栏模块、关系跳转、GET比较表单、清空、刷新、前进后退与无lang新入口保持正确语言。
3. 英雄／技能资料缓存隔离；另一语言加载、在线回退与离线已缓存查询不混版。
4. 每个启用语种覆盖列表、空、错误、加载、详情、来源、地图画布／图层／经济、路线运行／取消／完成、Diff／原始证据、开发工作台与数据库页。
5. 390px与桌面视口检查导航可用、全局入口可见、无页面横向溢出；键盘菜单打开／选择／Escape恢复焦点。
6. 单测检查语言优先级、链接、字典覆盖和参数一致；静态检查捕获新硬编码文案。复用原有语义／地图／缓存／浏览流程测试，运行范围pnpm check及docs:check。
